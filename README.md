# Golden Hour Press

Golden Hour Press is an offline multi-panel cover maker: drop in one or several photos, choose a cinematic layout and colour grade, then export a polished PNG with bold Anton lettering, a Pacifico neon-script subtitle, grain, halftone, vignette, badge, borders, and tilt.

## Run locally

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
node serve.ts
```

Open <http://localhost:8080>. The app makes 1080 × 1080 square, 1080 × 1350 portrait, and 1920 × 1080 landscape PNGs with the size picker and **EXPORT PNG** button.
